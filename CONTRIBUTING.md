# Contributing

Start with the [development guide](docs/developers/index.md) for setup, validation and
the code map. Only install the converters needed for your change.

## Report a problem

Use the bug-report template. Include the command, FigExport/Python/OS versions,
expected result and actual error. A minimal source file and config are especially
helpful. Remove private paths, credentials and confidential diagram content.

For substantial changes, open an issue to discuss the use case first.

## Submit a change

1. Fork the repository and create a focused branch.
2. Make the smallest change that solves the problem. Add regression tests for
   changed behavior and update the relevant docs page.
3. Run the checks in the development guide and open a pull request with the
   problem, resulting behavior and validation. Mention checks you could not run.

Keep discussions respectful. Contributions use the project's MIT license.
